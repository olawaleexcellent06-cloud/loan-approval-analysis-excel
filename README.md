# loan-approval-analysis-excel

## Dataset Information
- Dataset: Loan Approval Classification Dataset
- Records: 45,000
- Features: 14
- Type: Synthetic Dataset
- Target Variable: loan_status


## Analysis Process
The analysis was completed in the following stages:
### 1. Data Preparation
- Imported the Loan Approval dataset into Microsoft Excel.
- Reviewed the dataset for missing values, duplicates, and inconsistencies.
- Verified that the dataset contained 45,000 records and 14 variables.
- Confirmed that no duplicate records or missing values were present.

### 2. Exploratory Data Analysis (EDA)
- Calculated key performance indicators (KPIs) including total applications, approved loans, rejected loans, and approval rate.
- Used Excel functions such as COUNTIF, COUNTIFS, AVERAGEIF, and AVERAGEIFS to answer business questions.
- Analyzed applicant demographics, income, credit scores, loan amounts, and loan purposes.

### 3. Pivot Table Analysis
- Built Pivot Tables to analyze loan approvals across education levels and home ownership categories.
- Compared loan purposes, average income, credit scores, and average loan amounts.
- Summarized patterns across different applicant groups.

### 4. Dashboard Development
- Designed an interactive Excel dashboard using Pivot Tables, Pivot Charts, KPIs, and Slicers.
- Created visualizations to monitor loan approval trends and applicant characteristics.
- Enabled dynamic filtering for education level, home ownership, loan purpose, and loan status.
